# 神仙升职模拟器底层架构规划

## 核心模块

### Core
负责不可变基础规则：
- 时间
- 随机数
- 游戏状态
- 事件调度

### Domain
负责游戏实体：
- 玩家
- NPC
- 官职
- 品阶
- 境界
- 资源

### Systems
负责玩法系统：
- 晋升系统
- 任务系统
- 关系系统
- 洞府系统
- 功德系统

### Services
负责跨模块服务：
- 存档
- 数据加载
- 版本迁移

### Data
负责配置：
- 官职表
- 品阶表
- NPC模板
- 事件池

## 开发原则

禁止：
- 临时重复代码
- 为单一功能设计的封闭结构
- 破坏旧存档的数据修改

新增内容必须通过模块接口接入。
